## From the user (08.11) – which button does what
- Controls that ARE the main ON (= insert on of the channel): V-PLATE POWER; SHIMMER left pedal BYPASS; STEREO CHORUS left (modulator/chorus) BYPASS; TAP-DL power; BBD footswitch; DUAL PITCH POWER; PIA 560 IN/ON; EXCITER blue button (left); RACK AMP BYPASS footswitch; *AMP models: their POWER switch; FORTISSIMO 110 "ALL EQ" (only that one); MACH EQ4 IN/OUT.
- RESET footswitches reset only the knobs of their own pedal: SHIMMER right pedal (TWIN FILTER: lc, hc); STEREO CHORUS right pedal (filter); STEREO FLANGER left pedal (feedback pedal: feed lc, feed hc, feedback) and right pedal (filter). Need default values per knob (RESET values) – find out (desk RESET / definitions).
- STEREO DELAY: STEREO / CROSS / MONO = 3 buttons (mode).
- GEQ: the ON/OFF switch = TRUE CURVE (type), not power.
- EXCITER DRY, PSYCHO BASS DRY: their own function (solo/dry), not the main ON.
- RACK AMP CABINET SIMULATION footswitch = cab only (inside). *AMP models CABINET on/off = inside only.
- PULSAR: EQ1/EQ5 IN switches = inside only (two EQs).
- The 5 combined strips: every module ON/EQ/IN switch is inside only; the main ON switches all of them together.
- SPEAKER MANAGER: 3 devices on tabs FILTER (High Pass + type, Tilt EQ, Tilt Freq, Low Pass + type, Phase, Polarity Invert, Precision Delay, Position), DYN EQ (Attack Release Above/Below Gain Freq Q, Dyn EQ on, Threshold, Filter types LP6 LP12 Flat BP HP6 HP12, Ratio), LIMITER (Threshold, Release, Active, RMS/Peak, IN/GAIN/OUT meters). Graph on the right. User wants OUR design, as usable as our dynamic EQ: frequencies/curve on screen.
